# Install ScholarsPilot

**Release:** 1.0.0 · build 9 · signed Android pilot  
**Compatibility:** Android 7.0+ on ARM64 phones. Other architectures are not included in this APK.

1. [Download the APK from the official project release](https://github.com/RakibulIslam1/scholarspilot-downloads/releases/download/pilot-1.0.0-9/ScholarsPilot-Pilot-Android-v9.apk).
2. Open it on your phone. Android may ask whether the browser/file manager may install this downloaded app; review the prompt and allow installation only if you trust this project and artifact.
3. Choose Install, or Update if ScholarsPilot is already installed. Install over the existing app to preserve its data; do not uninstall as an update step.
4. Open ScholarsPilot, create/sign in to your account and verify your email. Complete any guardian approval required for the Bangladesh 13+ pilot.
5. Set up your monthly plan. Use Money for activity/accounts, Assistant for money questions and Settings for optional capture permissions.

The HTTPS API is configured in the app. A PC server is not needed. Free hosting can need time to wake; if a request times out, retry after it becomes available.

## Optional capture

SMS, notification access and microphone are separate permissions. Choose the financial senders you want to use and review current-month imports. For bKash alerts, enable the separate disclosed notification-capture option. If an alert omits the amount or fee, check the original wallet record and enter the actual values.

Some sideloaded installations restrict SMS/notification access. Respect the operating system's choices; manual entry and reviewed messages remain available. No developer-mode or USB-debugging step is required for normal expense recording. Permission availability is not guaranteed on every phone.
