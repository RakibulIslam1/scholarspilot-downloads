## Install

1. Open the download link on your Android phone.
2. Open the downloaded APK from Downloads. If Android requests it, allow
   installation from the browser or Files app you used, then tap Install.
3. Open ScholarsPilot. Its HTTPS service is already configured; no PC server is
   needed. Free hosting may take about a minute to wake up on first connection.
4. Create an account with your own email. The first pilot is Bangladesh, age 13+;
   students aged 13–17 need a separate verified guardian account and approval.

The app records manual accounts, expenses, budgets, CSV history and reviewed
financial messages. Optional selected-sender capture receives new SMS, not the
historical inbox. Add a text or voice purpose and review before saving. Preferred
currency reports preserve original transaction amounts. The Groq Assistant gives
stored-record explanations and general suggestions. Records are user-supplied;
the app does not transfer money or grant bank access merely by naming an account.

The source repository is private. This repository distributes the signed binary,
checksum and release notes. Keep the official signing identity for upgrades.
